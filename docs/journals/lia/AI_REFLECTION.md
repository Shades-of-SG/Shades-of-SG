# Lia's AI Reflection

At the start of the project, I used Copilot to help me with my code. I would manually have to input the code and I found myself having to go back and forth a lot with the AI to try and pinpoint errors in the code, a good majority of which stemmed from the fact that it did not know how the rest of the code worked so it would suggests changes or codes that were incompatible with the system. While it was helpful at times, it could also be frustrating when the code did not work as intended and I would have to search extensively to solve the issue. There were many times when I would have too modify the code such as when it used a different hashing method then the already available system or when it would wrongly identify an error. There were many times when I had to reject the code due to errors that were simply too hard to fix or because they were just not what I wanted. This part of the process was hard but I admit that it did challenge me to increase my understanding so that I could properly steer the AI in the direction I wanted such as being more specific with my prompts by sharing my understanding and pinpointing where I believed the issue to be.

Eventually, closer to the end of the project, I started using Claude. I admit I was a bit hesitant at first and while I often found myself dreading to do my work, I found that it was very helpful and was a massive jump from using Copilot. I often would spend some time ideating first and then writing out the prompt as extensively as I could to ensure that it would not stray far from what I had in mind and the Claude was very good at understanding my wants and adding them in. While it does take a very long time to work with from start to end, I do like how extensive it is. It's easier to work with since it can read and understand my entire repository which allows it to comply better with my wants. The amount of debugging I had to do had significantly decreased as it would run the tests by itself and since it could also see the entire repo, it was able to point out to me certain conflicts between my demands and the pre-existing system as well as do certain things that could only be possible with the AI being able to read the repo such as ensuring my UI matched everyone else's (The codes from my copilot significantly lacked UI) and also reused other people's code where possible to prevent overwriting. It was an overall much smoother process and there are definitely many perks to coding with an AI like this. I personally really enjoyed the planning feature which allowed me to better understand what it was doing and how the code would work and also allowed me to make changes if there was a misunderstanding. I also like that it would suggests certain things that I didn't think of that I think elevated my code even more. I didn't make a lot of changes to the code that it provided other than small UI changes such as a text that wasn't quite what I wanted it to be but even then, I usually added on the smaller issues into another prompt if I thought it was needed. 

I think the value added by AI is very significant, especially Claude. It helps users such as myself to execute an idea as well as build on it to make a feature or changes that may have otherwise taken a very long time to do so manually or possibly resulted in errors. Overall, AI tools in coding are a large help, especially for someone like me who is admittedly not the best at coding. It really helped me to not only execcute my work well and in a timely fashion but it also allowed me to have an understanding of how the code worked and what it was doing. It was also very helpful when I had to work on features that were outside the scope of the classroom learning. I think my prompting could use work but the AI itself has been very helpful throughout the entire process from ideating to executing.
