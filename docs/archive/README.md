# Documentation Archive

These files are preserved for traceability and possible submission evidence. They contain planning-era routes, feature states or workflow notes that are not authoritative for the current application.

- `ORIGINAL_CREATOR_WORKFLOW_JOURNAL.md`: detailed lifecycle/integration history.
- `legacy-use-cases/CREATOR_PLATFORM_USE_CASES.md`: original creator-side use cases.
- `legacy-use-cases/PUBLIC_PLATFORM_USE_CASES.md`: original public-side use cases.

Use `docs/project/USE_CASE_SPECIFICATION.md` and `docs/project/HIGH_LEVEL_DESIGN.md` for current behavior.
